**Sketchy UI** is a React component library built with [RoughJS](https://roughjs.com/) and [Tailwind CSS](https://tailwindcss.com/). It's designed for developers who want to break away from the "perfect" pixel-aligned web and add a bit of human touch to their interfaces.

## Features

- **RoughJS Rendering**: Every border is uniquely "imperfect" and sketched on the fly.
- **Virgil Font**: Pre-configured with the iconic handwritten font for a whiteboard aesthetic.
- **Modern React**: Built with React 19 and full TypeScript support.
- **Shadcn-like DX**: Components are templates that you own and can customize.

## Why Handwritten?

In a world of overly polished SaaS dashboards, sometimes a sketchy, organic feel makes your app stand out. It's perfect for:
- Note-taking apps
- Brainstorming tools
- Personal blogs
- Creative portfolios
- Educational tools
